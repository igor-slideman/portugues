# Português em três tempos

PWA для изучения европейского португальского: три подхода в день по 5–10 минут.

## Публикация на GitHub Pages

1. Создайте репозиторий, например `portugues`, и загрузите в корень все файлы с сохранением папки `icons/`:
   ```
   index.html
   data.js
   manifest.webmanifest
   sw.js
   icons/icon-192.png
   icons/icon-512.png
   icons/maskable-512.png
   icons/apple-touch-icon.png
   ```
2. Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → Save.
3. Через 1–2 минуты сайт появится по адресу `https://<ваш-логин>.github.io/portugues/`.

## Установка на iPhone

Откройте адрес в **Safari** → «Поделиться» → «На экран „Домой“». После первого открытия приложение работает и без интернета (кроме кнопки «Открыть Claude» и шрифтов при самом первом запуске).

## Обновление

После изменений в `index.html` поменяйте в `sw.js` строку `const CACHE = "pt3-v2";` на `pt3-v3` и т. д. — так телефон гарантированно подтянет новую версию. Страница сама по себе загружается сначала из сети, так что обычно хватает просто перезапустить приложение.

## Где хранится прогресс

Отметки «Сделано» сохраняются только на этом устройстве (localStorage). Если удалить приложение с экрана «Домой», прогресс пропадёт.
